# Student Marks Analyzer

A lightweight Python script designed to process student test marks, calculate fundamental statistics (total, average, highest, and lowest scores), and evaluate overall pass/fail results.

## Key Features
* **Total Calculation:** Computes the sum of all marks.
* **Average Score:** Calculates the mean score formatted to 2 decimal places.
* **Range Analysis:** Identifies the highest (`max`) and lowest (`min`) marks.
* **Result Evaluation:** Automatically checks pass/fail status based on a passing threshold of 40%.
